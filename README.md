# Life Style

A modern social networking Flutter app built with Firebase for authentication, Firestore, and Storage.

## App Details
- App name: Life Style
- Tagline: Connect • Share • Live.
- Android package name: `Com.lifestyle.social`
- Firebase project: `life-style-8d93a`

## Features included
- Login and Sign Up
- Home feed
- Stories
- Create Post
- Photo and video upload support
- Reels
- Messages
- Notifications
- Search users
- User profile
- Follow / Unfollow
- Like, Comment and Share
- Settings
- Blue and purple gradient modern design

## Tech stack
- Flutter
- Firebase Auth
- Cloud Firestore
- Firebase Storage
- Firebase Messaging
- Image picker
- Video player

## Getting started
1. Install Flutter SDK.
2. Ensure Android SDK is configured.
3. Run `flutter pub get`.
4. Add your Firebase Android configuration file:
   - `android/app/google-services.json`
5. Run `flutter run`.

## Important
This project is structured and ready for Android. For full production Firebase functionality, replace the placeholder configuration files with the real values from your Firebase console.
